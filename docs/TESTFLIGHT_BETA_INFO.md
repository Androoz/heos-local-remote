# TestFlight beta information

## Beta description

HEOS Remote is a simple local remote control for Denon HEOS players on iPhone and iPad. It connects directly over the local network without a HEOS account, cloud service, or external backend.

## What to test

Test automatic HEOS player discovery, manual fallback connection using an IP address, play and pause, volume and mute, and creating or dissolving speaker groups. In particular, verify that every room is found after restarting and that all rooms in a group can be set to the same volume.

## Test requirements

The test device must be connected to the same local network as the HEOS system. Allow local-network access when prompted by iOS.
