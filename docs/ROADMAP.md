# Roadmap

HEOS Remote is intentionally focused on fast local control, clear Now Playing information, and straightforward multi-room operation. Automatic discovery, manual fallback connection, groups, group volume, and reconnection to a saved controller address are implemented.

Possible future work includes:

- HEOS favorites
- Queue management
- Repeat and shuffle controls
- Widgets
- Siri Shortcuts and App Intents
- Apple Watch support
- An iPad sidebar layout
- Mac Catalyst support
- Optional themes
- Saved room scenes
- Secure CLI support on port 1256

The goal is not to reproduce the official HEOS app. A feature should be added only when it makes everyday control noticeably easier without making the primary interface heavier or less predictable.
